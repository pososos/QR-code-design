## 真實模型試用

`cement/demo_api.py` 是獨立展示服務，不是把管理API公開。僅模型狀態、推論與靜態頁，不提供清冊、標註、爬蟲端點。輸入最多12,000字元，POST位元組上限64KiB；單一推論鎖，忙碌回429。輸入不存檔或資料庫；不是完整多租戶服務（無帳號、每日配額或作業超時取消）。

```powershell
.venv/Scripts/python.exe -m uvicorn cement.demo_api:app --host 127.0.0.1 --port 8023
```

瀏覽 http://127.0.0.1:8023/ ，上傳後按「真實模型分析」。模型方法：既有TF-IDF＋LogisticRegression、檢索E5、檢索＋內容BGE重排。分類輸入是已擷取片段，非全文；標題與目錄由既有啟發式辨識。語意門檻沿用開發值0.8/0.02與0/1，未宣稱校準或適用新七類；只把已有實驗連成試用API，未新訓練。

實測 data/reports/model-demo-live-20260913.json：三種請求HTTP200，約0.86／7.17／8.06秒（含本機載入差異，非吞吐基準），第三種trace確實body retrieval→body reranker並棄權。舊自訓模型僅五類、少量開發樣本；缺artifact時停用選項，不能把預訓練檢索模型叫自訓成果。

## 分類評估與人工缺口

```powershell
.venv/Scripts/python.exe -m cement.evaluation --output data/reports/new-readiness.json --review-output data/reviews/new-batch.json --limit 21
.venv/Scripts/python.exe -m cement.evaluation --benchmark --output data/reports/new-comparison.json
```

readiness核對當前人工label、文字hash、membership、各split類別及語言提示。語言只是字元啟發式，不是真實語言標籤。当前沒有有效人工train membership、沒有test，validation也缺research／兩個新類；不挪用validation訓練。formal_training_ready保守固定false；並未新增混合訓練器。

21份小批審核輸出按來源輪流取樣，不按suggested_label；去除批內正規化全文重複，人工欄位空白。這是開發審核材料，非自然分布／獨立盲測，來源不等於家族；需人工确认家族与split。21是可逆工時預算，非研究推薦。檔案 data/reviews/development-next-20260913.json；可沿用review_pack製作閱讀包。

benchmark只用現有models/evaluation.json記載holdout IDs，排除訓練曝光、失效審核，三種方法比較；仍是重用的開發留出集，不宣稱独立成效。不同方法輸入長度／路由不完全相同，這是系統比較，非純模型因果實驗。正式七類評估與2:8混合訓練需人工資料，無法用模型自填補足。

## 自動流程

```powershell
.venv/Scripts/python.exe -m cement.pipeline --run-dir data/pipeline-runs/new-run --limit 25
.venv/Scripts/python.exe -m cement.pipeline --run-dir data/pipeline-runs/new-run --resume
```

新run凍結最多25個downloaded／parse_error IDs；逐份解析→FTS索引→弱候選→圖譜候選，可選--semantic更新語意快取。每步寫state.json與log，成功步驟resume不重跑；每步最多2次啟動，每個子程序最多600秒。全資料根目錄有pipeline.lock防雙worker；非pipeline程序仍需避免同時重解析。主程序意外死亡留下lock時須核對worker後才能移除，不能自動猜測鎖過期。新資料需新run。FTS目前全量重建，非TB增量承諾。

此流程不自動爬網、不重訓、不設定人工label或split；遵循cement-crawl Skill，不循環重試robots／限流來源。舊爬蟲仍是有界來源取得入口，尚未納入這個run的持久化重試。

實跑首次完成22個解析步驟後，FTS出現database locked；原因是寫入交易內再開store.documents連線執行schema。search.reindex改為寫入交易前取得文件清單，保留失敗log，再由--resume恢復。
