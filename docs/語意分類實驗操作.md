# 語意分類離線實驗操作

2026-09-12。沿用 D-005；不是線上分類服務或已自訓模型。模型官方使用說明保存在 data/*-model-card.md，模型 revision 保存在 config/semantic-models.json；E5 依分類／語意比較方式兩側使用 query:，attention-mask mean pooling 後 L2 正規化；reranker 依官方 AutoModelForSequenceClassification 取 logits，未當作機率。

## 執行

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-semantic.lock.txt
.venv/Scripts/python.exe -m cement.semantic_benchmark --method embedding --output data/reports/new-e5.json
.venv/Scripts/python.exe -m cement.semantic_benchmark --method reranker --output data/reports/new-reranker.json
# 若使用已下載且帶 revision.txt 的固定模型目錄：
.venv/Scripts/python.exe -m cement.semantic_benchmark --method reranker --model-dir data/reranker-fixed --output data/reports/new-reranker-local.json
.venv/Scripts/python.exe -m cement.semantic_summary --embedding data/reports/new-e5.json --reranker data/reports/new-reranker.json --output data/reports/new-comparison.md
```

只選 parsed，按 ID 排序，最多 12 份；模型輸入不含人工 label、metadata title 或來源提示，依正文前 1,500 字再以 tokenizer 截至 512 tokens。這是固定工程基準，未驗證為最佳片段策略。中英文等義描述共放一個候選，不挑選事後較佳語言答案。模型固定 CPU 4 threads；reranker 對五個類別全評，不先截 top-k。模型目前未設棄權門檻，輸出均為待驗證候選。

快取在 data/model-cache 或 data/reranker-fixed；需要磁碟存放權重。使用 safetensors、不啟用 trust_remote_code。已安裝相依另存 requirements-semantic.txt（直接套件）及 requirements-semantic.lock.txt（當次完整環境），原工作台鎖定檔不強加語意模型套件。

報告保存文字 hash、原文片段及頁碼、模型 revision、類別描述 hash、各類分數、截斷狀態與耗時。membership text_hash 失效者不計評分，人工標籤保留展示；曾參與開發資料不作盲測。研究類若皆失效，無法報其可靠成效。實驗不更改文件、人工 label 或 membership；仍需正常審核流程確認清理後文字。

官方來源：https://huggingface.co/intfloat/multilingual-e5-small 及 https://huggingface.co/BAAI/bge-reranker-v2-m3 。查核日期 2026-09-12，本輪讀取固定 revision README 的前綴、池化、截斷及推論程式段落；沒有重現其檢索研究實驗。初次 Hub reranker 下載停滯，改用固定 revision HTTPS 串流成功取得小檔並下載權重；未改用其他模型。
