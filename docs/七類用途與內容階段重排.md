# 七類用途與內容階段重排

2026-09-12。使用者要求 reranker 僅用在內容階段，新增實驗記錄與手稿筆記。這是新路由需求，不代表研究已證明 reranker 在所有內容分類均有效；沿用 D-005 的本地比較方式驗證。

## 新順序

標題 embedding → 未達門檻才目錄 embedding → 未達或缺目錄才限量內容 embedding → 未達才內容 reranker → 仍未達則棄權。純內容文件可直接從內容階段開始。標題與目錄完全不計算 reranker；每份最多一次內容 reranker 呼叫（七組類別／文件配對）。現有模型實驗仍讀已解析文字，未降低初次 PDF 解析成本。

標題擷取是可檢查的啟發式候選；長段落不冒充標題，但無法通用判斷所有缺標題格式。目錄缺漏則略過，不憑空補。內容限量 1,500 字，tokenizer 上限 512，保留截斷資訊。

## 分類邊界

|類別|ID|定義|
|---|---|---|
|研究與機理|research|整理完成的研究問題、方法、結果與結論|
|操作與工具手冊|manual|工具／軟體安裝、設定與操作步驟|
|工程應用指引|guidance|材料選用、施工、配比與品質要求／建議|
|安全資料|safety|危害、防護、急救與安全處置|
|產業與永續報告|industry|企業營運、財務、產業與永續揭露|
|實驗記錄|experiment_log|逐次試驗的日期、試體編號、操作條件、原始量測、異常與觀察|
|手稿筆記|manuscript_notes|未定稿的想法、討論、工作摘記與草稿，可打字或手寫|

包含實驗結果不一定是實驗記錄：正式研究報告仍以 research 為主。手寫也不必然是手稿筆記：有完整逐次試驗記錄結構者可能是 experiment_log。依主要用途判讀，難分仍可跳過；不新增自動多標籤。

## 實作位置

store.LABELS、API Label／ReviewSubmission、兩個頁面與閱讀包说明已擴充七類。config/semantic-labels.json 版本 purpose-bilingual-v2-seven-classes；config/term_mapping.json 版本 cement-purpose-v2-seven-classes，新增中英詞彙是未校準工程初值。人工原標籤不變，舊弱標籤保留但新版 rule hash 不將其當當前候選。舊五類模型實測只作歷史，不當七類效能；預訓練 encoder／reranker 未重訓，以七類描述重新推論。

每類延續既有配額：訓練人工10＋弱40、驗證人工5、測試人工10，總規劃由325變455。這是類別擴充後沿用配額的工程規劃，不是新研究建議，兩個新類目前零人工範例。需另收中英文實驗記錄與筆記後才可衡量辨識效果；掃描手寫辨識仍無 OCR 支援。

對圖譜：實驗記錄優先擷取試驗事件、條件、量測及異常；手稿筆記保留 draft 狀態、作者推測與未定結論，不因被抽取就當作既定事實。沿用原文明示／模型推論區分與待審核關係。
