## 實作與重跑

- cement/staged_classification.py：標題／目錄／內容擷取、各模型固定版本推論、門檻路由與報告。
- 標題為正文／封面自動候選，排除常見聯絡資訊；年報封面導航與題名混排已作規則處理。不是通用 PDF 版面理解，也未使用可能錯誤的 PDF metadata title。
- 目錄辨識前十個非空頁中的目錄標記或點線條目，找不到就跳過；不把摘要充作目錄。上限 1,500 字，正文亦限量 1,500 字。正文可能包含標題，但只在前階段未通過時參與。
- data/reports/staged-01 為封面標題修正前版本；staged-02 是最終版，包含 scores.json、thresholds.json 與 README.md。保留原文、頁碼候選、版本與各階段分數。
- 96 組為 4 個 E5 分数 × 4 個差距 × 2 個 reranker logit × 3 個差距。全部階段先算分再回放；推估路由耗時不含解析、初始化，不是實際動態部署吞吐。
- --reuse-scores 在模型 revision、類別描述一致時重用相同文字分數；限本地固定 CPU／長度設定，不是跨推論設定通用快取。--scores-input 只回放原快照，不刷新人工審核。

```powershell
.venv/Scripts/python.exe -m cement.staged_classification --output data/reports/new-staged
# 不再推論，只重新輸出既有快照的門檻比較：
.venv/Scripts/python.exe -m cement.staged_classification --scores-input data/reports/staged-02/scores.json --output data/reports/new-threshold-replay
```

22 項測試通過，新增標題／目錄隔離、封面導航、階段提前停止與棄權測試。人工標籤、membership 與線上審核 API 未更動。本輪是實驗路由，未新增自動寫入分類功能。

## 決策與下一步

依使用者明確要求及本批錯誤分析，採標題優先作後續架構方向；沿用 D-005 的模型官方推論依據。片段擷取與門檻皆工程試驗初值，沒有新研究聲稱其最優。保留級聯實驗，但暫不啟用 reranker 覆蓋人工真值或全量接管。下一步以新增、未參與調參的中英文來源比較；對模糊標題，可另測「先看目錄再 reranker」與目前「每階段立即 reranker」，不能在本次未跑比較前聲稱前者更佳。
