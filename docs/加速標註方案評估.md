# 加速標註方案評估

查核日期：2026-09-12。狀態：提案，未啟用新標註流程或更改 2:8。

## 結論與現況

推薦優先試行「多種證據的程式化弱標註＋衝突審核＋分層隨機抽驗」，其次以受限 LLM 教師補足難例，待有初始模型及足夠文件池再比較主動學習。自動化有望加速，但本案沒有資料證明比人工更準；人工也會出錯，因此評估標籤仍需一致的定義、證據及爭議裁決。

現有 13 份文件、8 份 parsed、5 弱候選、3 棄權、零人工真值。此規模逐份確認可能比新增系統更省時；新流程價值主要在後續擴充。解析失敗與研究類資料缺口不會由標註演算法自動解決。

## 研究依據與讀取限制

- Ratner 等，2017，Snorkel: Rapid Training Data Creation with Weak Supervision：https://arxiv.org/abs/1711.10160 。讀取摘要及書目；多個 labeling functions 可組合有雜訊監督訊號，研究有加速建模的結果。支持程式化標註可行性；不支持水泥領域固定準確率、比例、或任意相同規則投票必然可靠。未重現實驗。
- Bansal 與 Sharma，2023，Large Language Models as Annotators：https://arxiv.org/abs/2306.15766 。讀取摘要及書目；有限 LLM 標註預算配合選樣可改善研究中的語意相似／排序任務，普通不確定性選樣在其設定中表現不好。屬跨任務間接參考，不是五類文件用途實驗，所提 base/fine-tuned 模型分歧策略也不能直接套用 TF-IDF。
- Ghose 與 Nguyen，EMNLP 2024，On the Fragility of Active Learners for Text Classification：https://aclanthology.org/2024.emnlp-main.1240/ 。讀取摘要及書目；研究比較資料集、表示、分類器、預算對主動學習的影響，支持需與隨機抽樣做本地比較，不能假設主動學習一直較佳。未查閱全部實驗表格。
- 本次搜尋範圍為 weak supervision、LLM annotators、active learning text classification，優先原始研究。沒有查到可直接證實本案最優方法或人工替代比例的研究。既有 D-001／D-002 仍適用。

## 三個方向

|方向|本案實作提案|可靠性條件|優先度|
|---|---|---|---|
|多證據程式化弱標註|文件自身標題、章節結構、正文用途證據分別投票；網站類別只作輔助|保留衝突／棄權及逐頁證據；相似規則的相關性不能算成獨立確認|第一|
|受限 LLM 教師|只送標題、摘要、目錄及相關頁片段，要求五類或棄權、引用頁碼、原文片段；標註結果快取|引文能對上原文只證實出處，不證實分類正確；教師標籤另存，需抽驗；同模型多次一致不是獨立真值|第二，可選|
|主動學習|有初始模型後，從訓練池挑分歧、罕見來源及代表性文件請人審|比較同預算隨機抽樣；不能只審低信心樣本就估計全體正確率|第三|

例如安全資料表可由封面 Safety Data Sheet、危害辨識／急救／暴露防護章節共同支持；手冊可由 User Guide 與安裝／操作章節支持。這些是待驗證工程規則；正文引用研究文獻不應自動把手冊判成研究。每個訊號保存自己的判斷及理由，先以透明的合併策略作基準；只有八份文件時不優先估計複雜的 Snorkel label model。

教師可以是較強的生成模型，只在資料製作階段有限使用；最終部署仍是自訓單任務小分類器。這不要求部署小型生成語言模型。若不使用 LLM，第一個方向可獨立執行。此輪未呼叫付費標註服務、未傳送語料或指定模型。

## 建議流程與驗證

1. 固定用途定義與模糊案例處理方式。先整理品質、去重及來源／文件家族；開發池與評估池先隔離。
2. 在訓練池建立多證據候選；衝突、證據不足保持棄權。未確認候選不轉成人工 label，也不直接繞過 pending_weak_audit。
3. 人工看衝突／罕見案例以改進規則；另從各候選類別及來源隨機抽驗，包含一致案例，避免只看難例造成偏差。候選類別抽驗 precision；從完整文件池的獨立標註估 recall／漏判。
4. 標註報告記錄候選覆蓋率、各類正確率與抽驗分母／不確定性、衝突及棄權率、人工分鐘、API token 與實際費用。沒有量測前不承諾節省幅度。
5. 在固定、未用於調規則的人工評估資料上比較規則、人工訓練基準及混合模型的 Macro-F1／各類召回率；同時比較建置與審核總成本。少量樣本只作試行，不宣称泛化成效。

2:8 保持原規劃，不為湊比例製造標籤。若未來希望採接近全弱監督訓練，應以獨立人工評估及品質／成本比較另作決策；人工驗證與測試始終另計。分層抽驗量與放行門檻本輪不指定最佳數字。

## D-004（提案）：從逐份填寫轉向證據審核

依上列研究可行性與目前資料限制，建議下一個實作為「多證據弱標籤＋可閱讀證據審核」，保留既有盲評工作包；訓練池可呈現預標籤，獨立评估池不呈現。尚未實作，也未改寫資料庫真值。未採全量 LLM（成本與原始需求不符）、直接大量偽標籤自訓練（可能放大錯誤）、將同網站資料一律貼同標籤（用途混雜）。取得跨來源人工抽驗後重新評估方案，不把此提案當已驗證最優設計。
