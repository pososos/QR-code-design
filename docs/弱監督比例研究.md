# 人工與弱標籤比例：研究查核

日期：2026-09-12。問題是特定領域文件用途分類的人工／規則弱標籤訓練混合比例，不是 train/test 8:2、類別比例或已標註／未標註的半監督比例。

## 結論

本次針對水泥文件、domain text classification、gold/silver data、Snorkel、WRENCH 等檢索，未找到可直接套用到本案的固定建議比例。這是查核範圍內的結論，不是證明所有研究都沒有比例建議。

維持訓練集人工 20%／弱標籤 80% 作起始工程假設；不是文獻證實的最優比例。獨立人工驗證與測試另計。原規劃的 90% 抽驗精確率目標也是專案暫定目標，非查到的通用標準。

## 可用研究依據與適用邊界

1. [Snorkel: Rapid Training Data Creation with Weak Supervision](https://arxiv.org/abs/1711.10160)：透過 labeling functions 組合有雜訊的監督訊號，不需要人工訓練真值來去噪。這支持程式化標註的可行性，但不提供本案混合 2:8 的最佳比例。[官方教學](https://snorkelproject.org/use-cases/01-spam-tutorial/)另外區分人工 development/validation/test 的作用。
2. [WRENCH: A Comprehensive Benchmark for Weak Supervision](https://arxiv.org/abs/2109.11377)：跨多種弱監督任務進行評估；[作者程式庫](https://github.com/JieyuZ2/wrench)列出不同資料集的 train/validation/test 規模。這些集合大小不能直接解讀成人工／弱標籤混合比例。
3. [Two Directions for Clinical Data Generation with Large Language Models: Data-to-Label and Label-to-Data](https://pmc.ncbi.nlm.nih.gov/articles/PMC10782150/)：作者分析指出，對某一類別加入四倍 gold 大小的 silver 仍未改善，而資料品質與類別分布影響結果。這個局部例子不能外推成水泥用途分類的 1:4 建議。其 silver 來自 LLM，與本案詞彙規則不同。本文的相關分析由搜尋索引取得；直接開全文時遇存取驗證，因此未完成全文逐節查核。
4. [Weakly-Supervised Scientific Document Classification via Retrieval-Augmented Multi-Stage Training](https://par.nsf.gov/servlets/purl/10420110)：以類別名稱及未標註科學文件建立弱監督流程，可作領域詞擴展參考；使用 dense retrieval 與語言模型，並不是現行輕量詞彙分類器，也非固定混合比例實驗。相關方法摘要由搜尋索引核對。

## 本案可採取的做法

用可稽核的規則建立候選與棄權，再人工抽驗。維持同一獨立人工測試集比較人工基準、混合模型與規則基準。未來有足夠樣本時，可固定人工訓練數量，逐次加入弱標籤畫學習曲線，從驗證集決定是否需要 80%；不因預設比例忽略品質。
